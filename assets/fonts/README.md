# 한글 글꼴

- HUD/UI: Noto Sans KR — https://github.com/google/fonts/tree/main/ofl/notosanskr
- 서적: Noto Serif KR — https://github.com/google/fonts/tree/main/ofl/notoserifkr

Google Fonts 공식 저장소의 원본 가변 TTF를 수정 없이 포함했다. 두 글꼴은 SIL Open Font License 1.1이며, 각 원본 저작권 고지와 라이선스를 같은 폴더의 OFL 파일에 보존했다. 배포 시 함께 포함한다. 시스템 글꼴 의존 없이 한글을 렌더링한다.
