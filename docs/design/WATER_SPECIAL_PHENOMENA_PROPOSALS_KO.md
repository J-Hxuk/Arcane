2026-10-19. **이 문서는 전투 구현이나 확정 효과 목록이 아니다.** 이전 수치 강화형 시제품 3종은 유지한다. 아래는 주문마다 서로 대안인 A/B안이며 동시에 누적하는 설계로 확정하지 않았다. 영문 v05의 원본 효과를 기준으로 하고, XLSX 바이너리 직접 대조는 불가하다. 임의 경직·그로기·무적·자동 유도는 없다.

## 공통 물리 상태와 경계

S는 기존 B+O+T·압축 위험으로 계산한다. 기본 피해/속도/크기/사거리/넉백/비용의 순서 변형은 유지한다. 키나 순서 문자열을 조건으로 사용하지 않는다. 기존 raw 상태 r와 기준 B에서 다음을 산출한다.

```text
axis(x,s) = 0.5 + 0.5 tanh(x/s)
circulation = axis((r.flow+0.6r.persistence)−(B.flow+0.6B.persistence), 0.16)
pressure    = axis((r.cohesion−0.5r.form)−(B.cohesion−0.5B.form), 4)
confinement = axis((r.form+10r.persistence)−(B.form+10B.persistence), 6)
distribution= axis(r.spread−B.spread, 0.12)
motion      = axis((r.flow−0.6r.persistence)−(B.flow−0.6B.persistence), 0.16)
persistence = axis(r.persistence−B.persistence, 0.2)
score = 0.65axis + 0.20 S.stability/100 + 0.15 S.form/100
a = smooth((score−0.57)/0.18) × smooth((S.stability−25)/30)
smooth(x)=u²(3−2u), u=clamp(x,0,1)
```

distribution/motion/persistence의 이 정규화와 여섯 현상 판정은 **신규 제안**이다. 0~1의 방향성 없는 상대 잔차 지표이며 실제 속도/압력을 SI 단위로 측정한 값은 아니다. raw의 음수 흐름을 실제 반대 방향 벡터로 오해하지 않는다. 기본 S와 B는 수정하지 않는다. 경계에서 a가 0부터 연속적으로 커지고 추가 비용·변위·분리 거리·편향각도 함께 0부터 증가한다.

6안 모두 같은 시제품 Multiset의 순서를 바꾼 상태에서 OFF와 ON(강도 >0.1)이 존재하는지 시뮬레이션했다. 이것은 **조건의 도달 가능성 검사**이며 아래 새로운 전투·VFX가 구현됐다는 뜻이 아니다.

아래 추가 비용은 기존 B+O+T 물성 비용을 기준으로 한다. 현재 수치 강화형 시제품의 최대 12% 추가 비용과 자동으로 합산하지 않는다. 시제품 보너스의 대체/병행 여부 역시 채택 전 결정할 항목이다.

## 채택 전 공통 검증 계획

- 각 A/B는 대안이다. 함께 채택한다면 독립 자동 중첩하지 말고 점수·예산·최대 개수의 충돌 정책을 먼저 확정한다.
- 원본 직접 피해·속박·경감은 그대로 두고, 추가 현상은 별도 시간/공간 사건으로 기록해야 한다. 정답 키가 아닌 당시 S, 파생 score, 시전 조준 좌표계, 결정된 현상 파라미터를 저장한다.
- 발현 직전/직후의 효과량은 a를 통해 연속화한다. 두 핵의 출현 반경·궤도 곡률·편향각을 갑자기 고정값으로 켜지 않는다.
- 물리 사건은 벽 앞에서 sweep 정지하며 순간이동·자동 명중으로 대체하지 않는다. 소유권·피격 ID·한 주문 예산을 명시한다.
- 관측렌즈는 “물줄기가 옆으로 휩니다”, “두 중심으로 갈라집니다”, “수막에 닿은 탄체가 비껴갑니다”처럼 실제 사건을 설명해야 한다. 설계 후보를 현재 관측 결과인 것처럼 표시하지 않는다.
- 향후 실제 전투·보스·연속 재시전·VFX·프레임 예산 검증이 필요하다. **이번에 완료한 것은 수식 조건 도달성 검사이며 6개 현상의 실제 전투 구현 검증은 아니다.**
