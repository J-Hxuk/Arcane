> 이것은 데이터 변환본이며 구현 완료 보고서가 아니다. 세부 밸런스/상태판정의 `[제안]`, `[미정]`, `[확정]`은 원문 표현을 유지한다.
> 원본 전체 17개 시트는 `Arcane_Legacy_75종_전체시트_v05.md` 또는 패키지 내 개별 MD 참고.

## Codex 읽기 순서

1. `v05_시작하기`, `v05_결정기록`, `v05_확정대기`를 먼저 확인한다.
2. `상태판정_원칙`, `영창_12키설계`는 이 게임의 영창 구조를 설명한다. **예시 키 ↔ 조작 명령을 고정 레시피로 구현하지 않는다.**
3. 아래 75개 주문은 원본 `OH-001`~`OH-075`와 같은 ID를 사용한다. 다른 시트의 값은 각각 독립 항목으로 둔다.
4. `v04_*`, `v03_*` 시트는 과거 검토 이력이며 v0.5보다 우선하지 않는다.
5. 구현 상태는 원본의 작성 당시 표기이며 현재 프로젝트 코드와 대조해야 한다.
