# 정식 영창의 확장성 검토 — 후속 패치

이 문서는 설계 제안이다. 현재 일반 5입력, 개인 12키, 정식 16종은 유지한다. 별도 전속성 개편으로 영구 개화와 활성 주/보조 장착 및 후보 판정은 개선했지만 핵심/변조 층 분리나 입력 한도 확장은 구현하지 않았다. 75종 구성은 승인·확정하지 않는다.

## 현재 코드에서 확인한 병목

- `chant_identity.gd`는 조작의 정렬된 다중집합으로 후보를 고르고, `chant_engine_v2.gd`가 연구 자격·안정성·구조를 검사한다. `mana_variation.gd`는 같은 입력열의 B+O+인접 T 계산으로 피해·범위·속도·지속 등을 바꾼다.
- 즉, 조작 하나를 추가하면 물성 조절뿐 아니라 주문을 성립시키는 다중집합까지 달라진다. 플레이어가 압축만 조금 더 하고 싶어도 다른 주문 후보가 되거나 미완성이 될 수 있다. 정답 암기와 변형 탐구가 같은 입력 예산을 놓고 경쟁한다.
- 기존 22종 중 Lodestone, Brandlance, Ignition, 빙정방벽은 기존 구성이 5입력을 넘거나 짧은 구성이 미확정이다. Flintshot은 단순 길이보다 이중 압축에 의한 모든 순열 붕괴가 문제이고, 중립 운동파는 최신 구성이 미확정이다. 한도 증가만으로 여섯 종이 전부 해결되지는 않는다.
- 현재도 Root Flick/Tidebolt, Splinter/Ironlance처럼 같은 다중집합이 속성에 따라 나뉜다. 일반 캐릭터는 주속성이 후보를 좁히고, 전속성 시험은 명시적 대상 선택을 쓴다. 같은 속성 내 주문이 늘면 이런 구분만으로 부족해져 충돌·모호함이 커질 수 있다.
- 관측렌즈 없이 물성의 변화만 보는 것은 조작 언어를 학습하는 데 부담이 있었다. 이번 렌즈는 실제 입력 키의 의미와 상태 변화만 연결하며, 목표 주문의 정답을 제공하지 않는다.

## 대안 비교

| 안 | 장점 | 비용과 위험 | 미이식 주문에 대한 영향 |
|---|---|---|---|
| A: 5입력 유지·주문 자체 재설계 | 현재 입력/기록 구조를 그대로 사용, 빠른 전투 유지 | 75종의 구성·동일 속성 충돌을 개별 검토해야 함. 변형 입력이 정체성을 바꾸는 문제는 남음 | 새 짧은 구성 승인 필요. 압축 붕괴를 주문별 예외로 우회하지 않아야 함 |
| B: 핵심 조작과 변조 조작 분리 | 성립과 변형의 책임이 명확. 이미 발견한 주문을 일관되게 다듬기 쉬움. 개인 키표·최종 상태 계산 재사용 가능 | 두 단계의 경계를 플레이어에게 알려야 함. 부가 조작 비용·시간·연구 권한·복합 계보 검사 필요 | 기존 긴 구성의 어느 부분이 핵심/변조인지 설계자가 먼저 확정해야 함 |
| C: 해금 단계별 입력 수 확대 | 긴 원래 구성에 대한 이식 부담을 줄일 수 있음. 성장 보상으로 설명하기 쉬움 | 더 긴 입력이 실전과 연구 속도를 떨어뜨림. 충돌·공통 입력층 문제는 그대로. 저장된 규칙 버전 관리 필요 | 긴 4종에 도움이 될 수 있으나 미확정 구성·압축 붕괴는 별도 해결 필요 |

## 추천: B를 별도 실험 분기로 검증

현재 사용자 경험의 핵심은 같은 주문을 가늘고 빠르게 또는 넓고 묵직하게 다듬는 연구다. **핵심 구조를 먼저 성립시키고 변조를 추가하는 B**가 이 목적과 가장 잘 맞는다. A는 새 주문 설계 과정에서 보조적으로 쓰고, C는 추후 고위 연구를 위해 필요한 경우에만 검토한다. 이번 패치에서는 어느 안도 정식 입력에 적용하지 않았다.

제안 흐름은 다음과 같다.

1. 개인 대응표로 키를 조작 의미로 해석한다.
2. 핵심 단계에서 속성·계보·기초 구조와 주문 후보를 확인한다. 후보 충돌이면 임의 선택하지 않는다.
3. 변조 단계는 후보를 다른 주문으로 바꾸지 않고 현재 마나 상태를 계속 계산한다. 변화에 맞춰 비용·불안정·물성을 다시 산출한다.
4. 최종 방출에서 연구 권한과 최종 상태를 다시 검증하고, 발현과 자원 차감을 함께 확정한다.
5. 단계 경계와 당시 상태를 스냅샷에 저장한다. 재생은 새 규칙으로 다시 계산하지 않는다.

물성 수식의 현재 B+O+T를 그대로 쓸지, 핵심 종료 상태를 변조의 초기값으로 삼을지는 비교 실험이 필요하다. 초안의 `modifier_budget=2`는 시험 가정이며 확정 한도가 아니다. 고위 조작의 연구 제한과 주속성 포함 융합 제한은 변조로 우회할 수 없어야 한다.

## 소규모 데이터 초안

[chant_layers_draft.json](chant_layers_draft.json)은 기존 Tidebolt 구성만 예제로 쓴 비실행 초안이다. 새 키·새 주문·새 해금 규칙을 등록하지 않는다. 현재 런타임 어디에서도 읽지 않는다. 단계 구분 UI, 입력 시간, 성공률, 주문 충돌, 저장 재생 호환을 측정한 뒤 채택 여부를 판단한다.

권장 검증 지표는 같은 속성 내 후보 충돌 수, 처음 접한 조작 의미 추론 성공률, 주문 발현 후 변형 재현율, 영창 시간, 실패율, 마나 대비 실전 피해/제어 가치다. 75종 확정 전에 소수 기존 주문에서 비교하는 편이 적절하다.
