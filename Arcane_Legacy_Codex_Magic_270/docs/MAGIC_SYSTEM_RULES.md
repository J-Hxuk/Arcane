# Arcane Legacy — 마법 메커니즘·속성체계 통합 지식 베이스

> **문서 목적:** 이 파일을 처음 전달받는 사람이나 AI가 **Arcane Legacy의 마법이 왜 존재하고, 어떻게 발현하며, 동양·서양 속성이 무엇을 뜻하는지** 한 번에 이해하도록 만든 자급자족형 설명서.
>
> **기준일:** 2026-10-22 | **문서 유형:** 세계관 + 게임디자인 + 기술 개념 명세 + 현행 구현 상태 구분
>
> **가장 중요:** 이 문서의 `[확정]`은 **기획 원칙이 합의되었다**는 뜻이지, Godot에 구현되었다는 뜻이 아니다. `[가안]`은 실험할 수치·세부 방식이며, `[구현 보고]`는 Codex가 구현·자동 검사했다고 보고한 내용으로 사용자의 최종 수동 QA와 구분한다.

## 0. 이 문서를 읽은 AI에게 — 우선 숙지할 핵심 15가지

1. **게임의 주력 콘텐츠는 다크소울식 소수 강적/보스와의 1:1 교전**이다. 다수의 적에게 탄막을 뿌리는 게임을 전제로 스킬을 설계하지 않는다. 일부 보스만 소환수를 부를 수 있다.
2. 플레이어의 핵심 무기는 **마법과 지팡이**다. 지팡이 평타는 주력 딜링 수단이 아니라 저위력 접촉·마법 반응 트리거다. 이전 검 중심 구상은 최신 방향이 아니다.
3. **모든 마법은 플레이어가 직접 영창**한다. 주문 자동 시전·임의 자동 조합은 금지한다. 연구를 통해 입력을 익히거나 단축하는 기능은 가능하지만, 캐스팅은 자발적 입력이다.
4. 주문의 정체성은 **활성 마법 계열 + 최대 5개의 조작어 다중집합(Multiset)**으로 결정한다. 조작어 중복을 허용한다. **입력 순서가 바뀌어도 주문 ID는 동일**하다.
5. 반면 조작어의 **실제 순서**는 마나 구조의 **응집·운동·형상·지속·안정성·비용**과, 결과적으로 피해·사거리·범위·특수현상·VFX를 변화시킨다. 이 원리는 영창 시스템의 핵심 재미다.
6. 각 플레이어는 **개인별 12개 조작어 키 대응표**를 갖는다. 특정 알파벳 순서를 모든 캐릭터의 정답으로 하드코딩하지 않는다.
7. 과거의 **'첫 속성 시동어' 규칙은 폐지**되었다. 동양은 활성 주속성/음양 기질, 서양은 활성 원소·융합 조건에 의해 원소 정체성을 판단한다.
8. **동양 = 오행 5개 × 음양 2기질 = 10계열.** 서로 다른 오행 사이의 구식 이중융합은 동양의 최종 기획에서 폐지했다.
9. **서양 = 기본 4원소(불·물·바람·땅) + 서로 다른 두 원소의 6융합 = 10계열.** 융합은 결속(BIND)과 원소 개화·장착·마나 구조 판정이 필요하다.
10. 동서양에 결과가 비슷한 마법이 있어도 괜찮다. **만류귀종(萬流歸宗)**: 형성 원리·영창·이름·연출이 달라도 물리 현상과 충돌 판정을 일부 공용으로 사용할 수 있다.
11. **Shift 더블탭 = 초집중 모드, 이동 불가.** 초집중 시 이동속도가 70%가 된다는 과거 엑셀 문구는 **잘못된 구형 시험안**이다. 영창 전에 경량·표준·중량 유형을 미리 알 수 없다.
12. **영창 후 강제 안정화 대기시간은 추가하지 않는다.** '마나 구조의 안정성 판정'과 '시간을 기다리는 안정화 모션'은 다른 개념이다. 실패·과잉 소비에는 기존 **마나탈진** 체계가 있다.
13. 보스의 **짧은 빈틈 → 짧은 주문 또는 마나/포션 관리**, **큰 빈틈 → 4~5입력 고위 주문·초집중·HOLD 지속 공격**이라는 전투 루프가 기본이다. 270종마다 보스의 특정 패턴 사용 시각을 하드코딩할 필요는 없다.
14. **증기 = 고압 분출/저압 연막·조건부 은폐, 늪 = 독 누적 후 지팡이 접촉 반응, 모래 = 방어 마모·지속 틱 피해**다. 최신 검토에서는 모래의 **피해량 비례 마모 → 강한 이동 둔화 + 받는 피해 증가**가 강제 다운형 그로기보다 적합하다는 방향을 채택했다(세부 계수 미확정).
15. **동양 150종 + 서양 120종 = 총 270종은 설계 카탈로그**다. 2026-10-20 Codex 통합 보고 기준 정식 F5 등록은 **28종(그중 물 15종)**이며, 신규 음양/서양 270종이 전부 게임에 구현된 상태는 아니다.

1. **사용자가 직접 최신 대화에서 확정·정정한 결정(특히 2026-10-22 후반부)**.

5. Codex의 **구현 사실**에 관해서는 기획서보다 실제 코드·빌드·최신 검증 보고가 우선. **기획 합의와 구현 완료를 절대 혼동하지 말 것.**

## 1. 게임의 장르·전투 철학

- 장르: 중세·다크 판타지, PC 싱글 중심의 2D 비스듬한 탑뷰 액션 RPG/로그라이트 구상.
- 전투: 수가 적고 공격 전조와 패턴이 명확한 보스급 적을 상대. 플레이어는 **회피, 위치 선정, 패턴 관찰, MP 자원 관리, 마법을 직접 완성하는 숙련**으로 이긴다.
- 근접 보스는 탄막을 쏘는 경우가 드물다. 투사체 전용 방어막을 중복 생산하지 않는다. 방벽·마법 방호의 존재 이유는 **근접 충격 완충, 경로 변경, 접근 통제, 반격** 등이어야 한다.
- 보스의 강인도/차징 중단은 중요한 전투 자원이다. 모든 주문이 마음대로 차징을 끊거나 영구 속박해서는 안 된다. 보스 질량·저항, 돌진 중 위치 변위 제한, 시간형 속박 제한 등을 준수한다.
- 유저가 긴 입력을 외워 사용한다고 해서 자동으로 이기지 않는다. **마법의 준비 위험 + 적절한 사용 순간 + 명중 판정 + MP 기회비용**이 의미 있어야 한다.
- 주요 무기는 현재 설계에서 **지팡이**. 일반 접촉 타격은 매우 낮은 피해를 주되, 특정 주문이 남긴 표식·독 중첩 등을 **실제 적중했을 때만** 반응시키는 역할을 맡는다.
- 마나를 소모해 빈털터리가 되는 것은 원칙적으로 플레이어의 선택에 따른 리스크다. **마나 포션 존재**, 소울식 자원 관리 강조. 지팡이 평타로 반드시 보스를 잡을 수 있어야 한다거나 공격마다 자동 MP를 환급해야 한다는 전제는 없다. 대신 정상적인 세팅·MP·포션량으로 보스 체력을 소모할 수 있는지 **총 자원량 밸런스**는 검증한다.

### 보스전의 기본 페이스

| 전투 상황 | 주된 유저 판단 |
|---|---|
| 보스와 대치 / 패턴 관찰 | 이동·회피, 짧은 조작 준비, 연구한 영창 선택 |
| 보스의 작은 빈틈 | 짧은 영창/가벼운 견제, 마나 회복·물약, 유리한 위치 확보 |
| 보스의 큰 빈틈 | 4~5입력 고위 주문 완성, 초집중 정밀 영창, HOLD 광선·분사 |
| 보스가 강력한 공격을 차징 | 충분한 강인도 충격이 있는 경우에만 차징 중단 시도(실패 위험 존재) |
| 중독·마모·표식 형성 후 | 지팡이 근접 접촉·추가 주문으로 조건부 연계; 적의 반격 위험 감수 |

'고위 = 무조건 느림, 기초 = 무조건 빠름'이 아니다. **등급**(규모·복잡성)과 **시전 위험 분류**(경량·표준·중량·지속형)는 서로 다른 개념이다. 정확한 분류 수치는 아직 기획·검증 대상이다.

## 2. 전체 마법 속성의 세계관 구조

```text
ARCANE LEGACY MAGIC
├─ 동양 대륙: 오행(木 火 土 金 水)
│  ├─ 木 → 陽 벽람 / 陰 고림
│  ├─ 火 → 陽 홍염 / 陰 흑염
│  ├─ 土 → 陽 황악 / 陰 탁니
│  ├─ 金 → 陽 백섬 / 陰 묵철
│  └─ 水 → 陽 창류 / 陰 현수
│   (총 10계열 / 설계 150종)
└─ 서양 대륙: 4대 원소 + 이원소 융합
   ├─ 기본: 불 / 물 / 바람 / 땅
   └─ 융합: 증기(불+물), 뇌전(불+바람), 용암(불+땅),
             빙결(물+바람), 늪(물+땅), 모래(바람+땅)
    (총 10계열 / 설계 120종)
```

### 핵심 철학: 만류귀종(萬流歸宗) `[확정]`

동양이 단일 오행을 음양의 흐름으로 심화시켜 마법을 발현하고, 서양이 원소의 상호 작용과 융합으로 새로운 현상을 구성하더라도 **최종적인 자연 현상은 유사할 수 있다**. 동양 水陰과 서양 빙결은 모두 빙침을 만들 수 있고, 동양 土陰과 서양 늪은 모두 지면을 질척하게 할 수 있다. 이는 설계 결함이 아니라 **의도한 세계관 특징**이다.

- **동형 차용 허용:** 실제 투사체·피해·결빙·지형 판정 엔진을 공유해도 된다.
- **연출·마법적 설명의 차이:** 동양은 기질·오행의 발현, 서양은 두 원소의 결합이라는 경로를 다르게 설명할 수 있다.
- **차별화를 강제하지 말 것:** 억지로 새로운 피해 유형을 만들 필요는 없다.
- 단, 공유 판정 때문에 두 주문의 기존 ID·자원비용·기록을 덮어쓰지 않는다.

## 3. 동양 대륙 — 오행 × 음양 10계열

### 음양의 의미

- 양(陽)은 대체로 해당 오행의 **직접적·생성적·확장적 속성**을 심화한다.
- 음(陰)은 해당 오행의 **변성·침강·쇠퇴·절제·냉각 등 반대 결**을 심화한다.
- 음양을 통째로 별개의 원소처럼 취급하지 않는다. **같은 오행의 서로 다른 마나 기질**이다.
- 같은 물리 조작어를 사용하더라도 활성 오행·기질에 따라 주문 정체성, 구조와 VFX가 달라질 수 있다.
- **동양 내 서로 다른 오행 간 이중융합은 현재 기획에서 폐지**한다. 과거 문서의 木+火, 水+金 등 이중융합 예시는 구버전/서양 결속 로직과 구분할 것.

### 동양 10계열의 실전 성격

| 오행·기질 | 계열명 | 핵심 물성·이미지 | 보스전에서의 실질적 역할 | 영창 순서에 따른 대표 변화 |
|---|---|---|---|---|
| **木陽** | **벽람** | 생장·수근·줄기·활성 목질 구조 | 뿌리 구속, 성장벽, 보스의 접근 경로 변경 | 굵은 집중 뿌리 ↔ 넓게 퍼지는 가지·뿌리망 |
| **木陰** | **고림** | 부패·시듦·균사·쇠락 | 접촉 침식, 약화, 좁고 깊은 부패핵/넓은 균사장 | 고농도 부패핵 ↔ 넓은 저농도 포자·균사 |
| **火陽** | **홍염** | 연소·폭열·폭발·팽창 | 짧은 틈의 폭발 압박, 시차 폭발·열영역 | 밀도 높은 중심 폭발 ↔ 다층 폭열고리·확산 |
| **火陰** | **흑염** | 열에너지 결속·고밀도 광열·융합성 광선 | 정밀 열선, 제한된 직선·곡선의 지속/집중 타격 | 가늘고 강한 광축 ↔ 넓은 굴절·열선 껍질 |
| **土陽** | **황악** | 암석·융기·성채·지반 돌출 | 장애물, 접근 경로 차단, 융기 충격 | 두꺼운 석주 ↔ 넓은 지반 단차·암벽 |
| **土陰** | **탁니** | 침강·진창·점성·지층 함몰 | 적 발밑 침강, 감속, 접근 각도 교란 | 깊은 국소 함몰 ↔ 얕고 넓은 진창 |
| **金陽** | **백섬** | 강철·단결정·격자·단조 | 근접 충격 완충, 결정 구조물, 금속 반격·갑주 | 단단한 결정축 ↔ 넓은 금속판·다중 격자 |
| **金陰** | **묵철** | 절단·금속실·날·구속선 | 정밀 참격, 절단선, 짧은 구속·접촉 제어 | 날카로운 좁은 절선 ↔ 넓은 절단부채·금속실 |
| **水陽** | **창류** | 유량·수압·격류·순환·대해 | 충격·견인·밀기·다중 수류·위치 조정 | 단일 고압 집중 ↔ 회전·분산·집속하는 해류 |
| **水陰** | **현수** | 냉각·빙결·결정·예리함 | 냉각 구속, 정밀 빙침, 결빙 지형 | 예리한 단일 수정 ↔ 넓은 결빙면·결정 가지 |

#### 계열별 주의점

- **벽람 vs 고림:** 생장과 부패를 색만 바꾼 동형 주문으로 만들지 않는다. 한쪽은 *구조 생성/접근 제어*, 다른 한쪽은 *쇠락/침식* 중심.
- **홍염 vs 흑염:** 홍염은 팽창성 연소·폭발, 흑염은 집속 광열·융합/열선. 단순 불꽃 색상 차이가 아님.
- **황악 vs 탁니:** 위로 솟는 실체 암석 대 아래로 가라앉는 점성 지반. 탁니는 독을 필수로 하지 않으며 서양 **늪의 독·부식**과 구분 가능하지만 동일 진창 판정 차용은 허용.
- **백섬 vs 묵철:** 구조물·결정·강체 방호 대 절단·구속선. 탄막 방어 전용 주문이 지나치게 많아지지 않게 한다.
- **창류 vs 현수:** 흐르는 물의 **압력·운동** 대 물의 **냉각·결정·예리함**. 창류의 Hydra가 자동으로 얼음 용이 되지 않는다.

### 동양 주문 수·계승 상태 `[가안]`

- 10계열 × 15종 = **150종**. 각 계열당 기초·하급·중급·상급·고위 **3종씩**.

### 음양 선택과 다회차 성장 `[확정 방향]`

## 5. 마법 영창 시스템 — 주문 식별과 순서 변화

### 핵심 정의 `[확정]`

한 번의 영창은 다음 입력을 가진다.

```text
CastingContext = {
  world_system: Eastern | Western,
  active_school: 동양 오행+음양 또는 서양 기본원소/융합,
  unlocked_and_equipped: 해금·장착 정보,
  personal_operator_map: 플레이어별 12개 조작어↔키 매핑,
  ordered_sequence: [조작어1, 조작어2, ...],  // 길이 1~5, 반복 가능
  mana_state: 조작마다 실시간 갱신되는 구조,
  current_mana_and_overdraw: 잔여 MP·과잉 사용/탈진 상태
}
```

**주문 정체성 = 계열 식별자 + 조작어 Multiset**.

**주문의 물성 = 실제 입력 순서 + 현재 계열의 마나 벡터/계수 + 성공 가능한 최종 상태**.

예시(원리 설명용):

```text
같은 활성 계열에서 [ACCUMULATE, SHAPE, STABILIZE]
그리고          [STABILIZE, ACCUMULATE, SHAPE]
→ Multiset 같음 → 같은 주문 ID
→ 순서 다름     → 서로 다른 응집·운동·범위·비용·VFX 가능

다른 활성 계열에서 같은 Multiset을 사용
→ 계열 ID가 다르므로 전혀 다른 주문일 수 있음
```

- 조작어는 12종이며 **첫 입력이 자동으로 오행을 결정하지 않는다**.
- 최대 5개 조작어, **같은 조작어 반복 허용**. 길이 1~5의 가능한 Multiset 총수는 이론상 **6,187종/하나의 계열**이지만, 실제 설계·등록 주문 수와 같지 않다.
- 개인별 알파벳 키 매핑이 바뀔 수 있다. Excel의 ACCUMULATE 같은 **의미명**이 주문 정체성의 기준이며 고정 키 레시피가 아니다.
- 특정 Multiset을 입력해도 **주문 존재 여부 식별**과 **최종 마나 구조의 안정적 발현**은 다르다. 같은 주문의 어느 순열은 실패/불안정할 수 있다.
- **연구실 발견/학습 이력은 발현 허가의 필수 게이트가 아니다**는 것이 기존 정식 판정 방향이다. 올바른 계열 개화·장착, 영창 구조, 결속(해당 시), 마나·안정성이 실제 권한 및 성공 요건이다.
- 조작어 순서가 바뀐다고 별개의 주문을 자동 생성·무한 등록하면 안 된다.

### 서양 융합에 대한 BIND

- 기본 4원소 주문은 해당 단일 원소를 활성화하여 단일 주문으로 해석한다.
- 서양 융합 주문은 서로 다른 두 원소의 조합이 해당하는 6개 융합 중 하나여야 한다.
- **BIND(결속)**는 융합 구조를 표현하는 필수 조작/조건으로 기획한다. 정확한 결속 명세와 융합별 물성 계수는 새 속성체계용 엔진 검증이 필요하다.
- 결속 입력만 했다고 마법이 자동 발동하지 않으며, 두 원소의 개화·장착 조건과 최종 구조/마나 조건을 충족해야 한다.
- 과거 Godot의 *동양 오행 이중융합* 코드가 존재하더라도 **최신 동양 세계관에 그대로 유지하지 않는다**. 재사용 가능한 결속 엔진과 세계관 규칙을 분리해야 한다.

## 6. 마나 물성 계산 — B + O + T / raw 순서 보정

> 이 절은 **2026-10-20 Codex 물속성 15종 통합 구현 보고서**의 계산 모델을 정리한다. 아래 계수는 그 시점의 실제 오행5 엔진에 관한 기록이며 **신규 동양 음양 10계열과 서양 10계열에 동일 계수가 이미 구현되었다는 뜻이 아니다**.

### 기본 구조

조작어를 순서대로 `c₁, …, cₙ` 입력할 때:

```text
B = Σ V_e(c_i)                         // 조작어 벡터의 합, 순서 무관
w_i = 1.5^(i-1) / Σ_j 1.5^(j-1)       // 위치 가중치
O = 1.15 × Σ (w_i − 1/n) V_e(c_i)    // 순서에 따른 위치 가중 잔차
T = 0.20 × I_e × Σ interaction(c_i,c_(i+1))
S_raw = B + O + T                      // 실제 입력 순서에 따른 마나 구조
```

여기서 `V_e`는 **해당 계열의 각 조작어 마나 벡터**, `I_e`는 계열별 인접 상호작용 계수이며, `interaction`의 세부 정의/12개 벡터 표는 정식 코드·수식 참조표에 있다. **이 문서만으로 신규 20계열의 실제 벡터값을 임의로 산출하지 말 것.**

- `B`가 같아서 같은 조작어 Multiset은 같은 주문으로 식별된다.
- `O`와 `T`가 달라져서 순서별 **마나 흐름·속도·응집·지속·형상** 등이 달라진다.
- 최종 상태에는 정상화·압축 위험·안정성 경계·마나 비용 등이 적용된다.
- 물속성 통합 당시 `order_residual_mode=raw`, `property_version=raw-bot-1`, 순서 잔차 강조 gain **0.8**이 기본으로 보고됐다.

### 물성 보정 예 — 실제 구현 보고 기반

```text
f0 = clamp((S.C − 0.5*S.H)/65, −1, 1)
m0 = clamp(S.U − 0.6*S.P, −1, 1)

df = (raw.C − 0.5*raw.H) − (B.C − 0.5*B.H)
dm = (raw.U − 0.6*raw.P) − (B.U − 0.6*B.P)

f = tanh(f0 + 0.8*tanh(df/4))
m = tanh(m0 + 0.8*tanh(dm/0.16))
```

위 보고의 예시 배율:

```text
직접 피해 / DPS = 1 + 0.35*f
투사체 속도     = 1 + 0.50*m
사거리 예산     = max(0.4, 1 − 0.22*f + 0.15*m)
효과 반경       = 1 − 0.30*f
밀기/당김       = 1 − 0.35*m
유지시간        = max(0.4, 1 + 0.35*f − 0.25*m)
비용 보정       = 1 + 0.20*f + 0.10*abs(m) + 0.01*loss
```

※ `C/H/U/P`, `S`, `raw`, `loss`는 원래 엔진의 상태 성분/파생값이다. 새 속성체계로 넘어갈 때는 정확한 타입·차원·계열 계수를 실제 코드를 통해 조회한다.

### 영창 순서에 따른 질적 특수현상

상급·고위 주문은 피해/범위만 달라져서는 부족하다. 물속성 기존 통합 보고는 **마나 축에서 연속적으로 계산되는 특수현상(F)**을 9종에 시험 구현했다. 예시:

- **Eddywall:** 수류의 회전 정도에 따라 첫 투사체 편향 각도 변화(구형 v05 투사체 방어 역할; 최신 v06의 근접 보스전 역할 개편안과 **충돌**할 수 있음).
- **Undertow:** 물살에 단순 중심 견인 외에 접선 방향 와류 성분이 생김.
- **Trident:** 실제 3개 수류의 집속·분산 변화. 총 피해 예산은 유지.
- **Razorflow:** 자동 유도가 아닌 **발동 때 확정한 곡선 수류**. 집중/운동 성향에 따라 휘어짐.
- **Confluence:** 2번의 견인 펄스의 시차 변화.
- **Abyssal Lock:** 압력 해제 고리(임의 추가 HP 피해 없음).
- **Thalassa:** 상반 방향으로 회전하는 여러 물층.
- **Hadal Verdict:** 총 피해의 일부가 시차를 두고 충돌하는 고압 후속 타격; **추가 보너스 피해가 아님**.
- **Hydra:** **7개 독립 수류**의 궤적·집속·분산·곡률 차이. 실제 적중한 갈래만 타격.

**금지:** `키를 A→B→C로 누르면 특별히 2배 피해` 같은 고정 키 문자열 레시피. 효과는 반드시 **조작어가 만든 실제 물성 상태**에서 연속적·재현 가능하게 발생해야 한다.

## 7. 직접 영창·입력·초집중·HOLD의 조작 규칙

### 일상 플레이의 입력 맥락

| 행동 | 입력/원칙 | 상태 |
|---|---|---|
| 이동 | WASD, 게임 내 마우스 이동도 사용 | 기존 조작 기반 |
| 이동 영창 | **Shift 유지**하고 직접 조작어 입력 | 기존 방식 |
| 초집중 진입 | **Shift 더블탭** | **[확정] 이동 불가** |
| 주문 방출 | 활성 영창이 완성된 상태에서 **LMB** | 플레이어가 직접 방출 |
| 지팡이 공격 | 활성 주문 방출 문맥이 아닐 때 **LMB** | 신규 기획 방향, 입력 우선순위 구현 검증 필요 |
| HOLD 발현 | HOLD 주문 완료 후 **LMB 누름을 유지** | `[확정 방향]` 지속 발현. LMB 해제 시 중단 |
| 취소 | **Esc** | 기존 수동 취소 |
| 회피/점멸 | **Ctrl**(점멸은 연구 개화 후) | 월드 이동 체계; 초집중과 충돌 처리 필요 |
| 속성 장착 | 구 Godot에서는 Tab 대상 슬롯·Alt+숫자 또는 후속 보고에서 휠 등 변경 이력 존재 | **새 동서양 UI 키 결정을 코드로 확인**할 것 |

- **HOLD는 5입력을 초과해 조작어를 계속 넣는 마법이 아니다.** 1~5조작으로 주문을 완성한 다음, LMB를 누르는 시간만큼 출력이 이어진다.
- 연구실에서는 실제 마나 변화를 관찰하고 Shift 해제 시 시험 자동방출하는 기존 테스트 흐름이 보고됐으나, **전투에서 주문이 자동 발동하는 것은 금지**한다.
- 과거 Codex의 초집중 구현 보고에는 추가 제약과 회복 효과가 있었으나, 새 동서양 20계열과 HOLD까지 포함하는 **최종 입력 상태 머신은 미검증**이다.

### 초집중 `[확정: 이동 불가 / 구체적 능력치 가안]`

- Shift 더블탭 후 **제자리에 멈춰** 직접 영창·방출한다.
- 핵심 보상 후보는 **마나 물성의 정밀 제어, 안정적인 지속 출력, 집중된 수류/광선의 조준·흔들림 제어**다. 자동 영창, 자동 유도, 추가 무적은 주지 않는다.
- 일반 영창의 90%, 초집중 70% 이동 배율이라는 v1.1 시험표 중 **초집중 70%는 사용자에게 명시적으로 거부되었다.** 실제 규칙은 이동 불가(0%).
- **'안정화 시간 20% 감소' 같은 보상은 삭제**한다. 추가 안정화 대기시간 자체가 최신 설계에 없다.
- 초집중 시 마나 소모·물성 보정·후딜의 구체 숫자는 미정. 기존 구현의 회복/비용 수치는 신규 설계 확정값으로 자동 승격하지 않는다.

### 시전 분류·실패

- 조작어 입력 이전에는 발현할 주문이 **경량·표준·중량 중 무엇인지 알 수 없다**.
- 입력이 완성되어 **주문과 마나 상태가 판정된 뒤**에야 분류가 정해지는 구조를 원한다. 엑셀의 분류표는 과거 예측치이며 **실제 B+O+T 판정 알고리즘이 아직 미확정**.
- **'영창 후 0.12초/0.25초 강제 안정화' 같은 시간 대기는 채택하지 않는다**. 시전 실패와 마나탈진 등 위험 체계는 남긴다.
- 영창 중 피격·중단·취소, 실제 방출 후 회복·점멸 가능 구간 등 **전투 타이밍 상수는 미정/시험 필요**. 장문의 기다림을 자동 삽입하지 말 것.
- 기존 연구 시스템의 **마나탈진(Mana Overdraw)**, 실패 비용, 부족 MP 상태를 활용한다. 실전에서는 마나를 플레이어가 관리하고 포션을 사용한다.

### HOLD — 연속 분출·광선 `[확정 방향 / 숫자 미정]`

- 광선, 화염방사, 고압 수류, 마모성 모래 분사 등에서 활용할 수 있다.
- **LMB 눌림 동안 지속 적중 판정**, 주기적 MP 소모 및 피해 틱, **LMB 해제 시 즉시 중단**.
- 짧게 끊어도 어느 정도 피해/가치가 있어야 하고, 오래 유지하면 높은 누적 효율 또는 질적 연출·효과의 강화가 있어야 한다.
- 채널 유지 동안은 **한자리에서 방출**하는 종류가 핵심. 초집중과 연계 가능하지만 둘을 자동으로 동일 상태로 취급하지 않는다.
- 고정 자세 자체가 보스의 패턴에 노출되는 리스크다. 중도 해제와 적절한 후딜 사이의 균형을 검증한다.
- 제안된 HOLD 후보: **Whiteheat, Reactor Filament, Stellar Loom, Furnace Breath, Pressed Jet, Scouring Thread**.
- 최대 지속 3초, 틱 0.2초, 초집중 MP/s +20%, 해제 후 0.55초 등의 v1.1 값은 **구형/시험 숫자**. 최신 결정에 의해 **추가 안정화 시간은 삭제**하며, 나머지 수치는 확정되지 않았다.

## 8. 마법 연구실·발견 경험

### 궁극적인 플레이 경험

플레이어는 연구실에서 '실패했네 → 다른 키 아무거나 눌러보자'가 아니라, **마나가 구조적으로 변하는 모습을 관찰하고 가설을 세우는 연구자**가 되어야 한다.

1. **관찰:** 현재 활성 계열의 마나 구체·축·입자·파형 등 시각화를 관찰한다.
2. **실험:** 조작어 한 개를 추가하고 바로 **응집·순환·형상·유동·발산·안정성 변화**를 본다.
3. **비교:** 입력 전후 스냅샷을 기록·재생해 어느 조작어가 어떤 물성 변화를 줬는지 추론한다.
4. **재실험:** 같은 Multiset의 순서를 바꿔 **주문은 같지만 발현 특성이 달라지는 현상**을 확인한다.
5. **기록:** 개인의 영창 실험 일지, 관측렌즈, 스승의 의미 있는 피드백을 통해 나름의 영창 스타일을 정립한다.

### UI/연구 피드백의 중요한 규칙

- **실시간 마나 변화는 플레이어에게 보여준다.** 정답 키 조합을 무작위로 탐색하는 게임이 되어선 안 된다.
- **첫 속성 시동어는 더 이상 없다.** 연구실·스승이 구버전 '첫 글자에 맞는 오행'을 설명하면 오류다.
- 관측렌즈/스승은 ***실패 이유를 이해할 단서***를 주되, 모든 정답 레시피나 수치형 F 점수를 무조건 공개할 필요는 없다.
- 마법을 발견했다고 자동으로 발동하지 않고, 발견 기록이 없어도 제대로 된 물성과 해금 상태면 구조적으로 발현할 수 있다는 원칙을 보존한다.
- 단서(책·스승·환경/관찰) → 안정 공명 → 촉매 검증 → 직접 의식 → 사용자가 수동 개화 확정하는 **기존 속성 개화 연구 흐름**은 상위 구조로 유지할 가치가 있다. 새 음양·서양 분기에 어떻게 연결되는지는 구현 설계 대기.

## 9. 세 융합 속성의 전용 전투 메커니즘

### 9.1 증기: 고압 공격 / 저압 은폐 `[사용자 확정 방향]`

- **기본 주문**은 고압 공격과 저압 연막 계열의 역할이 분명한 편이 좋다.
- **상급·고위 일부**는 마나 물성에 따라 고압/저압 분출 비율·증무 잔향이 **연속적으로 변하는 복합형**을 허용한다. 주문의 주역할을 완전히 뒤집지는 않는다.
- 저압 연막은 **시야선(LOS) 및 표적 추적 약화**의 실제 필드를 만들 수 있다. 보스가 *마지막으로 본 플레이어 위치*를 향해 공격하거나 소리·근접 감지로 찾도록 하면 전술적 재미가 있다.
- **완전 무조건 은신/보스 AI 영구 무력화는 금지**. 연막 안에 있어야 하고, 공격 시 은폐가 깨지는 방향을 권장.
- 대표 고위 **Pressure Cathedral**: 거대한 증기기관 돔/성당, 축압 노즐. 순서에 따라 좁은 고압 주포와 넓은 저압 분무가 변화. 실제 시야를 가리는 연출이 보스의 공격 전조를 가리지 않도록 함.

### 9.2 늪: 독 누적 → 지팡이 접촉 반응 `[사용자 확정 방향]`

```text
늪 주문으로 독성 진창/부식 효과 부여
    ↓
보스에 독 스택·독 DoT 누적
    ↓
플레이어가 접근해 지팡이 타격을 실제로 적중
    ↓
독 스택 일부 소모 → 독성 반응/분산 피해·약화
    ↓
다시 독을 누적시키는 전투 루프
```

- 핵심은 **위험한 접근을 감수하고 독 상태를 능동적으로 활용한다**는 점.
- 독 틱 자체가 자동으로 지팡이 접촉 판정을 만들지 않는다. 무조건 큰 폭발을 매번 일으키는 방식도 아니다.
- 진창·지면 점성은 土陰 탁니와 겹쳐도 좋다. **늪의 추가 정체성은 독/부식**.
- 독 중첩 상한 2, 지팡이 반응 내부 쿨다운 4초, 반응 DoT 2초 등은 v1.1의 **시험값**으로 확정 아님.
- 보스의 독 내성·면역, 돌진·위치 경로, 지팡이 실제 충돌 판정 존중.

### 9.3 모래: 마모·틱 피해·침식 노출 `[최신 채택 방향 / 수치 미정]`

**이 항목은 v1.1 엑셀의 '적중 10스택 → 0.85초 완전 행동불능 그로기'보다 늦게 논의된 최신 방향이다.**

최신 합의·긍정 평가:

1. 모래의 주력은 **한 방 폭딜이 아닌 다단·지속 틱 피해**다.
2. 보스의 일반 강인도(Poise)와 **별개의 마모 상태/게이지**가 있다.
3. 같은 1회 적중이라도 피해 1과 피해 100이 똑같은 마모량을 만드는 것은 부자연스럽다. 따라서 **실제 적용된 모래 피해량에 비례해 마모가 누적**되는 방향이 적합하다.
4. 마모 문턱에 도달하면 **보스를 완전히 다운시키기보다 큰 이동 둔화와 받는 피해량 증가(침식 노출)**를 부여하는 게 소울식 전투에 더 적합하다.
5. 보스의 공격 전조·공격 모션은 원칙적으로 정상 속도를 유지. 이동과 방향 전환만 크게 둔화시켜 공정성을 보존한다.
6. 마모와 받는 피해 증폭·기존 방어력 감소가 중복돼 DPS가 무한 증폭하지 않도록 보호해야 한다.

피해량 비례 마모의 **출발점 예시 공식(미확정)**:

```text
ΔAbrasion = K × D_sand_applied / BossMaxHP

D_sand_applied = 방어·내성 등을 반영한 실제 모래 속성 HP 피해
K              = 보스 HP 비례 누적량을 조절하는 계수(실험으로 정함)
Abrasion       = 일반 Poise와 분리한 보스별 마모 누적 상태
```

- 장점: 틱 개수가 달라도 총 유효 피해가 같다면 기본 누적량이 유사하고, 보스 HP 규모 차이도 정규화할 수 있다.
- 위험: 마모의 방어 감소로 실제 피해가 증가→마모가 더 빨리 증가하는 양성 피드백. 피드백 제한·상한·저항 필요.
- 스택 소멸은 '5초 지나면 전량 삭제'보다 **점진적 감소**가 유저에게 덜 가혹하다는 제안이 있다. 확정 숫자 없음.
- **침식 노출 시험 예:** 보스 이동속도 −45%, 받는 피해 +12%, 2초 지속, 12초 재발동 제한. **예시일 뿐**.
- 고위 **Dune Sovereign**은 모래뱀으로 적을 휘감아 반복 접촉 마모·틱 피해를 주며, 좁은 고밀도 연마 ↔ 넓은 분진 확산으로 변형한다.
- 이전 v1.1의 **보스 방어력 감소 상한 12%, 일반 적 20%**도 시험안이다. 받는 피해 증폭과 병존할지는 따로 결정해야 한다.

## 10. 상급·고위 마법과 영창 순서에 따른 VFX 설계 원칙

### 주문 등급

- **기초 → 하급 → 중급 → 상급 → 고위**의 5단계.
- 고위일수록 무조건 피해량이 높은 게 아니라, **독자적인 물리현상·전술 선택·고유 실루엣·큰 준비/사용 리스크**를 가져야 한다.
- 기초/중급과 상급/고위의 차이를 단순히 크기·밝기·입자수로 처리하지 않는다.

### 상급·고위의 3단계 연출

1. **응집/준비:** 마나가 원소·기질 고유의 형태로 모임.
2. **발현:** 거대한 실루엣이 실제 판정과 함께 등장(수룡, 성당, 석거인 팔, 모래뱀 등).
3. **해소/잔상:** 물리적으로 납득 가능한 흔적·수류 분산·파편·잔류 마력으로 마무리.

### 용어 사전

- **오행(五行):** 동양 木·火·土·金·水.
- **음양(陰陽) 기질:** 같은 오행의 상반된 마나 흐름/발현 방향.
- **개화:** 해당 계열을 마법 자격으로 획득하는 성장·의식 과정.
- **활성/장착:** 실제 이번 영창이 참조하는 마법 계열. 영구 개화 이력과 다름.
- **조작어(Operator):** 개인 키 대응표의 의미 있는 마나 조작 단위.
- **Multiset:** 순서를 무시하지만 조작어 반복 횟수는 보존하는 집합. **주문 ID 식별 기준**.
- **Permutation:** 같은 조작어 Multiset의 서로 다른 실제 입력 순서. **마나 물성 변화 기준**.
- **B+O+T:** 무순서 기준 벡터 합 + 순서 위치 가중 + 인접 조작 상호작용.
- **raw:** 순서 잔차를 자르지 않고 물성 차이에 반영하는 기존 구현 경로.
- **마나탈진:** 무리한 마나 사용·불안정 발현에 따른 불이익 시스템. 기다리는 안정화 타이머와 다름.
- **초집중:** Shift 더블탭, 이동 불가 상태에서 정밀·수동 영창.
- **HOLD:** 영창 완료 뒤 LMB 키다운으로 발현 지속, 키업으로 중단.
- **만류귀종:** 서로 다른 동서양 마법 경로가 동일한 현상·판정에 도달 가능.
- **Poise/강인도:** 보스 공격 차징/경직과 연동되는 일반 충격 자원. 모래 마모와 별개.
- **침식 노출:** 모래 누적이 문턱을 넘으면 강제 다운 대신 둔화·피해 증폭을 부여하는 최신 기획 방향.

---

**최종 한 문장:** Arcane Legacy의 마법은 **플레이어가 오행·음양 또는 원소융합을 연구하여, 개인적인 조작어 순서를 직접 영창하고, 마나의 연속적 물성 변화를 이용해 소울식 보스전의 빈틈을 활용하는 전술적·실험적 시스템**이다.
