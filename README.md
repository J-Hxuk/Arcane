# Arcane Legacy

Godot 4.7.2 / GL Compatibility 기반의 **싱글플레이 2D 탑다운 판타지 액션 RPG 프로토타입**. 소수의 강력한 적과 보스전, 직접 입력하는 영창, 실험과 관측을 통한 마법 발견이 중심이다.

> **기준: 2026-10-23 GitHub `master`에 반영된 구현.** 이 파일은 실행과 탐색을 위한 안내다. 오래된 구현 변경 기록은 여기에 반복해서 쌓지 않는다. [현재 구현 현황](docs/CURRENT_STATE_KO.md) · [현재 기획 기준](GDD_v1_0_KO.md) · [변경 이력](docs/CHANGELOG_KO.md)

## 실행

1. Godot에서 [project.godot](project.godot)을 열고 **F5**로 실행한다. 메인 씬은 `scenes/world_main.tscn`.
2. 중앙 마을에서 시작한다. 북서쪽 연구실, 북쪽 들판, 동쪽 탐험로와 수호 기사 보스를 탐험할 수 있다.
3. 개발 중에는 게임 화면에서 **F2**로 격리 시험 패널을 사용할 수 있다(정식 배포 기능 아님).

## 조작

| 키 | 현재 동작 |
|---|---|
| RMB | 클릭한 도달 가능한 목적지로 이동 |
| 마우스 / LMB | 조준 / 평상시 검 공격, 영창 시 명시적 방출 |
| Shift 유지 | 이동 영창(기본 이동속도 80%) |
| Shift 빠른 두 번 | 초집중 영창(이동 정지·회복 속도 증가), 방출 LMB |
| 연구실 Shift 해제 | 유효한 입력이 있다면 한 번 방출·실험 기록 |
| Esc / Space | 영창 취소(화면/모드에 따라 처리) |
| Ctrl | 이동술 연구 전 회피, 연구 후 점멸(마나 5, 최대 216px, 쿨다운 0.9초) |
| E | 연구실·도서관·상점·촉매·쉼터 등과 상호작용 |
| I / M / J | 인벤토리 / 지도 / 발견 영창 기록 |
| 1 / 2 | 체력 / 마나 포션 |
| Tab | 변경할 속성 슬롯을 주 ↔ 보조로 전환 |
| Alt+1~5 | 火 / 水 / 木 / 金 / 土 선택 |
| Alt+6 | 보조속성 해제(주속성 해제 불가) |
| Alt 유지 | 속성 선택 HUD |
| 마우스 휠 | 카메라 확대·축소(0.65~1.6) |
| F2 | 개발 빌드 시험·설정 패널 |

UI가 열린 상태나 영창 진행 중에는 일부 입력이 제한된다. **옛 '휠로 속성을 선택·Alt+휠로 줌' 설명은 현재 규칙이 아니다.**

## 현재 마법 규칙 요약

- 기본 속성 **木·火·土·金·水**를 각각 개화할 수 있다. 개화 목록과 활성 **주속성 1개 / 보조속성 최대 1개**는 별도 관리한다. 과거 無/VOID는 현재 여섯 번째 독립 오행 슬롯이 아니라 중립 호환 기록에 남는다.
- 개화는 서적/스승·공명 실험·촉매 검증·직접 의식·수동 확정을 거친다. **단일 주문은 주속성**을 따른다.
- 융합은 양쪽 개화 및 주·보조 장착, BIND·계보·마나·안정 구조를 검사한다. **과거 결속 연구·발견 기록은 정식 시전 허가 조건이 아니다.**
- 마법은 매회 **직접 영창**한다. 캐릭터별 영창 키 표를 보존하며 버튼 클릭으로 주문을 자동 시전하지 않는다.
- **주문 정체성:** 속성/계보 + 최대 5개 조작의 Multiset(중복 허용). **순서별 결과:** 실제 순서에 따른 B+O+T·tanh 물성, 안정성·발현 및 특수현상 변화.
- 정식 설정(`data/chant_v2_prototype.json`): `rules_version=8`, `property_version=raw-bot-1`, `order_residual_mode=raw`, `order_gain=0.8`. 옛 'raw 적용 보류'는 폐기됐다.
- 원격 저장소의 정식 등록 주문은 **28종**, 이 가운데 **水 OH-061~OH-075의 15종**이 포함된다. **75종 전체는 구현되지 않았다.** 설계 원본은 저장소의 v05 Markdown이며, 로컬에서 개정한 후속 원본은 별도 대조가 필요하다.

## 월드·마나·검증

연구실의 실시간 마나 구체·실험 비교·기록 재생·관측렌즈, 인벤토리·대장간·골드·포션·지도, 야외 몬스터 재생성 및 수호 기사 보스전의 코드가 존재한다. 마나 부족분은 일반 마나를 음수로 만들지 않고 비공개 `mana_debt`로 처리한다. 저장 스키마는 **v6**이며 캐릭터·키표·발견·연구 기록을 보호한다.

- 물속성 QA: **F5 → F2 → 물15 QA 연구실/일반 표적/수호기사**. [수동 QA 체크리스트](docs/qa/ARCANE_LEGACY_WATER15_MANUAL_QA_KO.md).
- 테스트 통과 보고, 실제 Godot 창 합성 입력, **사용자 수동 플레이 승인**은 서로 다르다. 이번 문서 정리에서 게임 테스트를 새로 수행한 것은 아니다.
