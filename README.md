# Arcane Legacy — 2D 탑다운 RPG

최신 작업은 **전속성 개화·활성 슬롯 자유 전환·영창 판정 개편**이다. [통합 구현 보고서](IMPLEMENTATION_REPORT_FOLLOWUP_KO.md)에 이전 밸런스·연구 점멸·관측렌즈·몬스터 재생성 패치와 함께 정리했다. 촉매 개화, 개인 키표, 인벤토리·상점·지도는 유지한다.

Godot 4.7.2 Compatibility에서 `project.godot`을 열고 **F5**로 실행한다. 최신 개인 영창 해석기를 바로 사용하는 일반 게임으로 시작한다. 별도 CMD나 문법 전환은 필요 없다. 기존 키표·관찰 스냅샷·개화·발견·연구 증거는 보존하며, 현재 사용 키표는 저장의 `active_chant`에 분리한다. 최초 통합 전 원문은 `.formal.bak`으로 남긴다.

마을 북서쪽 연구실은 **입구 E → 실시간 마나 관측**으로 들어간다. 가운데 구체에 현재 영창이 반영되고 양옆은 저장된 실험의 단계·시간 재생이다. 직접 조작 시험장에서는 실제 표적 피해·속박·밀어내기를 확인한다. 마나 자연 회복은 연구실 8/초, 야외 3/초다. 관측렌즈를 켜면 입력한 키의 실제 개인 대응 의미, 계산된 물성 변화와 짧은 조작 자막을 표시한다. 내부 수치나 정답 조합은 표시하지 않는다. 기초 이동술 연구는 이 연구실에서 시작하며 속성 슬롯을 쓰지 않는다.

木·火·土·金·水 다섯 속성을 각각 영구 개화할 수 있다. 개화 목록과 현재 장착한 주속성 1개·보조속성 최대 1개를 독립적으로 저장한다. 신규 개화는 서적 또는 스승 → 안정 공명 → 같은 속성 촉매 검증 → 직접 의식 → 수동 확인이며 추가 개화의 간섭 안정화 조건도 유지한다. 단일 주문은 현재 주속성으로 판정하고, 융합은 실제 결속 입력·장착 조합·기존 결속 연구가 필요하다. 보조 장착만으로 융합하거나 주문을 발견하지 않는다. 시전 시작부터 방출·취소까지 속성을 고정하고, 끝난 뒤 다시 바꿀 수 있다.

대장간에서는 물약 수량을 정해 구매한다. 체력 물약은 12금·45 회복, 마나 물약은 15금·40 회복이다. 마나 물약은 기존 정신력 초과분부터 회복한다. 수량과 보관 골드는 저장하며 효과가 없거나 저장이 실패하면 물약을 차감하지 않는다.

마을 **북문**은 북쪽 이끼 들판으로 이어진다. 두 종류 몬스터 다섯 마리가 분산되어 있고, 공격 전조를 벗어나 피할 수 있다. 처치 골드는 바닥에 떨어져 접근 시 수거된다. 처치 후 활성 야외 시간 60초가 지나고 플레이어와 500 이상 떨어진 화면 밖에서 새 개체로 재생성된다. 개체별 드롭은 한 번만 수거되며, 미수거 드롭이 같은 배치에 2개 쌓이면 다음 재생성을 기다린다. 동쪽 성문·탐험로·수호 기사 보스전도 유지한다.

개발자는 **F5 → F2 → 상단 옵션 켜기**로 현재 월드에 즉시 적용한다. 오행 전체 개화·개화한 모든 쌍 결속·점멸 강제 해금은 위치나 캐릭터를 바꾸지 않는다. F2를 닫으면 그대로 월드에서 시험하고 Tab/휠로 속성을 고른다. 일반 저장은 보호하며 설정 종료 시 시작 시점의 원래 진행을 복구한다. 기존 자원·골드·포션·적 생성·연구 초기화 버튼도 현재 세션에 적용할 수 있다. 별도 프리셋 시험은 선택적으로 남긴다. 릴리스에서는 비활성이다.

연구실 관측 화면과 직접 시험장에는 **주속성/보조속성 선택 칸**이 있다. 개화한 후보만 보이고 중복 장착과 영창 도중 변경을 막는다. 미개화 속성의 이론 공명은 기존 관측 대상 선택기를 사용한다.

현재 정식 문법 등록은 **16종**이다. 과거 22종 중 6종은 승인된 짧은 구성이 없거나 현 수식에서 붕괴해 실행 등록을 보류했다. 삭제 없이 과거 발견·학습·영창 기록을 보존한다. 미이식 목록과 이유는 최신 보고서에 명시했다. 75종 전체 및 속성별 점멸 효과는 이번 범위가 아니다.

검증은 실제 사용자 저장 대신 프로젝트 내부 격리 파일만 사용한다. 최신 [tests/run_attributes.ps1](tests/run_attributes.ps1)의 기본 실행은 새 속성 검사, `-Formal`은 정식 회귀, `-Previous`는 이전 후속 패치, `-Core`는 과거 호환 회귀다. `-Window`는 실제 렌더 창, `-Realtime -Window`는 실제 60초 재생성 검사다. 최신 로그는 `.task002_artifacts/attribute_loadout/`에 있다. 합성 입력·컨트롤러 검사와 사람의 장시간 플레이 판단은 구분한다.

서적에는 Noto Serif KR, UI에는 Noto Sans KR을 포함한다. [원본 출처·라이선스](assets/fonts/README.md)를 배포물과 함께 유지한다.
